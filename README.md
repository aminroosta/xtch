# EPUB to XTCH

[Convert at xtch.pages.dev](https://xtch.pages.dev/). Preview and export DRM-free EPUBs for the Xteink X4 Classic. Conversion runs in your browser and works offline after the first visit.

With Node.js 22+, run `npm run dev` to preview at [localhost:8788](http://localhost:8788/). For Cloudflare Pages, use `npm run build` and publish `dist/`.
